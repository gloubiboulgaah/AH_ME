# Player Controls

## Keyboard

| Key | Action |
|------|--------|
| W | Move forward |
| A | Move left |
| S | Move backward |
| D | Move right |
| E | Interact |
| F3 | Toggle debug overlay |

---

## Interactions

Press `E` when another player is nearby to open the interaction menu.

The game detects nearby players using the distance between their positions.

From the interaction menu, the player can send a private message or use an emote.

---

## Mobile

Use the virtual joystick to move the player.
