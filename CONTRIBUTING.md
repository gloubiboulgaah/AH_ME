# Contributing

## Workflow

Créer une branche depuis `main`.

Exemple :

```bash
git checkout -b feature/my-feature
```

---

## Commits

Utiliser des commits explicites.

Exemples :

```text
feat: add debug overlay

fix: correct joystick input

style: improve HUD layout

docs: update development guide
```

---

## Pull Requests

Avant de créer une Pull Request :

- vérifier que le projet compile ;
- tester les fonctionnalités modifiées ;
- supprimer le code mort ;
- demander une revue de code.

---

## Style

- utiliser TypeScript ;
- respecter ESLint et Prettier ;
- éviter les gros commits regroupant plusieurs fonctionnalités.
